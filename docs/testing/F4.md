## Before you start
- Run the F4 migration on the dev project once, in Supabase **SQL Editor**: `supabase/migrations/20261009120000_f4_search.sql`.
- Check that it ran: the query below shows one row where all five columns are `true`. If any is `false`, run the migration (again). Running it twice is safe.

```sql
-- Query 0: is the F4 migration applied?
select
  exists (select 1 from pg_extension e join pg_namespace n on n.oid = e.extnamespace
          where e.extname = 'pg_trgm' and n.nspname = 'extensions')                          as pg_trgm,
  exists (select 1 from information_schema.columns
          where table_schema = 'public' and table_name = 'listings'
            and column_name = 'search_text')                                                   as search_text,
  exists (select 1 from pg_proc where proname = 'search_compact'
            and pronamespace = 'public'::regnamespace)                                         as search_compact,
  exists (select 1 from pg_proc where proname = 'search_listings'
            and pronamespace = 'public'::regnamespace)                                         as search_listings,
  to_regclass('public.listings_active_published_idx') is not null                              as newest_index;
```

## 8. Privacy and speed (Supabase SQL Editor)
Each query pretends to be a visitor for a moment and only reads. Run each query on its own.

```sql
-- Query 3: a visitor (not logged in)
set local role anon;
select set_config('request.jwt.claims', '{"role":"anon"}', true);
select
  (select count(*) from public.search_listings(p_limit => 300))      as found_by_search,         -- same as live_ads
  (select count(*) from public.listings where status = 'active')       as live_ads,
  (select count(*) from public.search_listings(p_q => 'Villa'))        as found_by_building_word,  -- 0, unless "Villa" is in an ad's title, description or landmark
  has_function_privilege('public.search_listings(text, integer[], text[], text[], integer, integer, integer, text[], text, date, double precision[], text, integer, integer)', 'execute') as can_search; -- true
```

